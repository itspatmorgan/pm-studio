Website began as Design Studio's Marketing starter and was renamed and rebuilt from itspatmorgan.com on 2026-11-01.

## Included

- **Theme:** colors, the base radius, and motion tokens come from the kit's `tokens.css`, the file the site imports, which `styles/theme.css` imports as written. Studio fits its `:root` and `.dark` rules to the theme boundary and reads the tokens from the fitted result (`cssFitting: 'fit'`), so nothing is copied. Type sizes, spacing, and widths are Tailwind's defaults, limited to the steps the site and its labs use.
- **Fonts:** Geist and Geist Mono as packages; Geist Pixel Square as `assets/fonts/GeistPixel-Square.woff2`.
- **Images:** the `debut` card textures, used by the `.texture-bg` class.
- **Button:** the site's shadcn base-nova button (`src/components/ui/button.tsx`).
- **Site shell:** `PageLayout.astro` with the Sidebar, Header, MobileNav, PageHeader, and Footer, rewritten in React. Links render through a `renderLink` prop so prototypes can navigate between their own pages; the theme toggle flips the theme boundary rather than `<html>`.
- **Lab page:** the frame from `src/layouts/LabLayout.astro`, without the site sidebar and footer.
- **Pixel wave text:** `src/components/PixelWaveText.astro` and `src/scripts/pixel-wave.ts`, rewritten in React; the helpers return cleanup functions.
- **Logo:** the four-pixel mark and its hover interactions (`src/components/layout/Logo.astro`, rewritten in React).
- **Shared site pieces:** Badge, Print photo, Project card (with each case study's live visual), Lab card (with live previews), Article list item, Kind words, Section header, and Media row, extracted from the site's pages and components.
- **Generative art:** the deterministic generators, `LiveEditorialVisual`, `GenerativePatternSurface`, `ArtCanvas`, and `UAMark`, re-exported from the kit (see below). Pattern Engine, the editor for them, is its own prototype.
- **Theme hooks:** `useDark`, `useReduced`, and `usePhone`, imported from `@itspatmorgan/kit` (see below).
- **Case study scenes and demos:** the scene player and stages (`case-study`), and the Sublime, query builder, expansion, Design Studio and Studio case demos, all from the kit. `CaseStudyPage` and `Slide` port `CaseStudyLayout.astro` and `Slide.astro`.
- **Design Studio landing styles:** `styles/site/ds-landing.css`, from the `<style>` block of `src/pages/design-studio.astro`.
- **Tabs and Tooltip:** kept from the Marketing starter and restyled by the new tokens. The site has no equivalent yet.
- **Prose:** the site's `.prose` rules, rewritten as plain CSS under the theme class and renamed `.site-prose`, because Studio's Tailwind setup generates @tailwindcss/typography styles for any system using the class name `prose`.
- **Libraries:** Hugeicons (`libraries/icons`), Motion (`libraries/motion`), and html-to-image (`libraries/html-to-image`). IBM Plex Mono and Comic Neue are package fonts for the expansion and Studio case demos.

## Shared kit

The scene player and stages (`case-study`), the case study and Design Studio demos (`sublime`, `query-builder`, `expansion`, `design-studio`, `studio-case`), the generative art engine, and the theme hooks are not copies: they come from `@itspatmorgan/kit`, a package in the site's repository (`packages/kit`) that the site imports too. The system depends on it at a pinned commit in `package.json`; each kit component imports its own stylesheets, as on the site, and Studio fits them to the Website theme when it bundles them. The system's own components and the prototype's pages use some kit classes directly, so `styles/theme.css` imports those stylesheets too, the same ones the site's pages import. To take a site change, move the pin to the new commit and run `pnpm install`.

## Adaptations

- The site toggles dark mode with `.dark` on `<html>`; Studio uses `[data-color-mode="dark"]` on the theme boundary.
- The site's `@theme inline` color aliases are generated by Studio from the semantic names, so components use `var(--secondary)` rather than `var(--color-secondary)` in custom CSS.
- Logo styles live in `styles/theme.css` under the theme class, and its keyframes are prefixed `website-theme-`. They predate fitting; new ports can be written as the site writes them.
- The site's button drops its `dark:` overrides here, because Studio's dark tokens already supply those values.

- Page styles the site writes in `<style>` blocks became files under `styles/site/`, imported by `styles/theme.css` as written. Studio fits them to the theme like any other imported CSS. One change: on the site, Astro's scoped styles outrank the kit's, so a rule here that overrides a kit stylesheet names its base (`.cs-hero.ds-hero`, `.cs-stage.sc-lesson`) to win on specificity rather than on load order.
- `system.ts` declares `origin: null`: credit comes from the libraries list instead. shadcn/ui is credited on Button, Badge, Tabs, and Tooltip, and itspatmorgan.com on everything ported from the site. Add a new component's slug to the right library's `components`.
- Internal component files start with `_`, so the Systems pages list one documented entry per folder; each folder's `index.ts` is its public surface.
- `useDark` follows the theme boundary's `data-color-mode`, not `.dark` on `<html>`. The generative art and Lab previews use it.
- `StudioQuote`, `StudioPress`, and `StudioLesson` are the site's Astro components rewritten in React, with their styles in `styles/site/studio-case-astro.css`.

The shadcn MIT notice is retained in `LICENSE`.
